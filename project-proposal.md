## Project Description
We will use Baxter's integrated camera to generate a 3-D map of an object. This will include capturing images with the camera placed an known points, and developing an algorithm to stich the images together into a 3-D map. This will involve using Python libraries such as OpenCV. We will use the book *Robotics, Vision and Control* by Peter Corke as a reference.
